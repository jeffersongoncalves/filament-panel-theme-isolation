## v3.0.0 - 2026-03-30

Initial release of Filament Panel Theme Isolation plugin.

Isolates dark/light theme preference per Filament panel using prefixed localStorage keys, preventing theme conflicts when multiple panels share the same domain.

### Compatibility

- Filament v5
- Laravel 11.28+
- PHP 8.2+
